## 映射结论

三份原草图均在 inflate 中写 D7=0，在 deflate 中写 D7=180；这证明代码发出的值，不单独证明开关负载侧的 ON/OFF。用户提供的卖家阈值（小于1500µs OFF、大于1500µs ON）与该解释冲突。当前真实驱动中的反向候选映射及注释不是独立实测证据，不能用它裁定原草图错误。当前证据不足以选定任一映射，OFF／ON 参数继续未定。

## 唯一下一项实物核验

安排 **D7 电子开关的隔离假负载特性核验**，泵不参与。该核验不使用本次输出禁用草图发信号，不上传或运行原始循环草图。由具备相应测量条件的人员，先审核夹具、模块输入额定和测试方法；保持现有整机单 USB 架构，不擅自另加负载电源。

核验前须确认气动负载不能获得能量、无残压，USB 是该测试负载唯一供能源且有可触及的实际断能路径，无其他供电或回灌。若无法满足隔离条件，或没有合适仪器／受控信号源，就报告缺项，不在现有接线上尝试。

一次核验需返回的记录：

| 项目 | 所需观察 |
|---|---|
| ON／OFF | 实际信号脉宽、负载侧电压／电流、从 ON 切回 OFF 的关断延迟及是否可靠；不得仅观察指示灯或空载电压 |
| 无信号 | 从 ON 和 OFF 分别停止脉冲／移除信号，记录关断、保持或其他行为及延迟；高阻与固定 LOW 不混为一项 |
| 上电／掉电／恢复 | USB 切断后负载确实无供能；上电及恢复无自动导通；Nano RESET 时输入行为仍需在后续获批夹具中确认，不能用信号源替代并宣称已测 Nano |

输入幅值、允许脉宽和假负载额定先按可确认资料确定，不盲扫。只有模块允许时才覆盖旧 Servo 端点；返回信号实测值而不是仅返回 0／180。负载断能和输入信号丢失分别记录。此项不要求现在启动真实泵。

## OFF 确认后的最小改动范围（待准入和明确授权）

保留 `d7_start_stop` 原样作为默认输出禁用版本；另外准备 D7 专用输出版本，不修改统一固件、三模式时间线、D5 或 D6。

- 仅增加一个 D7 Servo 对象，显式记录经测量的 ON／OFF 脉宽和依据；初始化预置已验证 OFF，首次 attach／RESET 过程须有实测覆盖，不能认为预置就保证无脉冲毛刺。
- 显式 START 才请求 ON；STOP、主机超时及单次上限统一请求已验证 OFF。保持复位不恢复、超时锁定及重复 START 不延时。实体单次上限另按批准方案确定，不能默认10秒安全。
- 日志分开记录“OFF 已发送”和“实体 OFF 已观察”。没有反馈传感器时，不伪造自动确认物理 OFF。
- Windows 端只调整专用固件身份和状态识别，保留连接／START／STOP／日志；不改展览 UI、不自动连接或重启。

这是一份待实施的最小改动规格，不包含可启用的输出实现。若 OFF 不能可靠建立，停止在输出禁用版本。可靠 OFF、独立于程序的断能、无压或限压／泄压条件和异常处置确认后，仍需用户明确授权，才能实施及上传实体测试版本。
