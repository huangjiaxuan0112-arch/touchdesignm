# Phase 3B Step 5：实体硬件验证准备清单

**仅准备，实体项目全部待测，未批准 Step 6。** 本次不改固件、不打开 COM、不上传、不改线、不通电。下述负载拆离与台架连接由合格操作者另行审核执行；不是给现有整机重新插 USB 的指令。

## 1. 已知接线；OFF 仍未知

用户确认：Nano＋扩展板，Windows 单 USB 同时供电和通信，原系统曾正常运行。每路使用型号未知的 RC 电子开关，须逐只验证，不能假定三只特性相同。

| 管脚 | 负载 | 旧 inflate() | 旧 deflate() |
|---|---|---:|---:|
| D5 | 电磁阀 | Servo.write(180) | Servo.write(0) |
| D6 | 抽气泵 | Servo.write(180) | Servo.write(0) |
| D7 | 充气泵 | Servo.write(0) | Servo.write(180) |

旧端点约对应 2400／544 µs、约 20 ms 重复，仅作已验证的虚拟信号参考，不是开关规格。`0`、`180`、`detach()`、LOW 均不是已知 OFF；Step 4 的 STOPPED 也只是逻辑记录。

## 2. 操作者现在做：断电观察，不拆改接线

1. 拔 USB、排除其他电源／回灌，确认无残余压力。合格人员确认无电压后才做通断／电阻测量；“电脑没发命令”不算断电。
2. 拍整机、扩展板跳线、三只开关正反面及泵／阀铭牌，贴 D5／D6／D7 标签，记录端子文字、极性、损伤及可见保护元件。旧报告中的 6 V 泵资料须对照实物。
3. 画现状接线图：逐路追出信号、逻辑供电／参考地、负载供电／回路，以及 USB VBUS 经 Nano／扩展板到负载的路径；不能凭线色或插头外观认线。

交付合格操作者：**照片＋端子／供电图＋铭牌／可确认规格**。若不能确认供电、输入边界和输出形式，先停在断电检查，不试加电。

## 3. 后续台架前提：泵和阀始终断开

合格人员先审核独立夹具图；在断电状态将所有气动执行器与台架供能路径物理隔离，贴签固定。只断信号或软件 STOP 不够。若不能拆离或不允许调整测试连接，就不做带电项。

- 使用隔离、限流的低压电源、就近保险、手动总断电及适合开关输出形式的电阻假负载／受控电子负载；电压、限流与负载功率按已确认边界选定，不猜数值，不回灌 Windows USB。
- 独立脉冲源提供已确认额定内的输入；先核对电平／参考连接，不与 Nano 输出并联。万用表测电压／电流，隔离输入示波器或合适差分探头同步捕获信号和负载瞬态。核对全部仪器与 PC 的接地路径；不得拆保护地或把普通地夹随意夹到开关输出。[Tektronix 浮地测量说明](https://www.tek.com/en/documents/technical-brief/floating-oscilloscope-measurements-and-operator-protection)
- 测前按负载资料写明 OFF 最大漏电流／残余电压、允许关断时间及误导通判据；未知则不能判 PASS。指示灯或空载电压不能单独证明 OFF。

## 4. 三路逐只执行的最低测量

每项记录：供电、输入、假负载、负载电压／电流、峰值、关断延迟和恢复状态，附波形。失效项目分别从此前 ON 与 OFF 开始，各至少三次；这不等于寿命或额定认证。

| 项目 | 必须做什么／记录什么 |
|---|---|
| 真正 OFF | 在已确认输入额定内测短／中／长脉宽及双向转换，找 OFF／ON 窗口、滞回和关断延迟；仅在允许时覆盖旧 544／2400 µs，不盲扫未知电平或脉宽。 |
| 无信号 | 分开测停止脉冲并保持末电平、信号移除形成高阻、允许范围内静态高／低；记录关断、锁存或振荡。 |
| 上电／恢复 | 无信号、已测 OFF、此前 ON 条件下冷启动和断电复电；若供电可分，测逻辑／负载不同上电顺序，捕获误导通及自动重启。 |
| 掉电／欠压 | 在夹具允许范围内测控制电源先失去而负载电源仍在，以及实际 USB 路径的电压下降／恢复和回灌；不能分开的条件须标未覆盖。 |
| Nano RESET | 仅在批准的假负载夹具、且板上既有固件已确认不会自动驱动时，不打开串口捕获真实上电／RESET／恢复的信号及输出；固件身份不明则待测，不为此上传或运行旧草图，不用发生器断信号冒充复位实测。 |
| 独立关断 | 假负载 ON、信号保持 ON，操作独立负载断电，确认三路均失去供能；恢复装置后不自行动作。不得依赖电脑、Nano 或协议 STOP。 |

主机停通信、信号丢失、USB 掉电须区分；本台架不访问 COM，不能据此声称已测 Windows 串口断开／重连的全部电气行为。意外导通、保持导通、超标或不确定即 FAIL／待测；若模块自身不失效关断，必须加入独立抑制并重测系统，不能只改软件。

## 5. 准入前必须补齐的保护

- **独立切断负载能量：** 装置可触及、额定合适、覆盖三路且无旁路／回灌，复位不自启。USB 总断电可兜底，但不能证明 Nano 保持供电时负载可独立禁用。
- **USB 与负载电气裕量：** 核对 USB 口／线缆、扩展板、开关、接插件及保险额定，电机启动／堵转资料和线圈感性关断保护。以受控假负载电流阶跃检查代表性的并发电流、压降／温升，不通电或堵转真实泵。电阻假负载不能证明感性承受能力。裕量成立则保留 USB-only；不成立才另审供电方案，不预设必须另加电源。
- **独立限压／泄压：** 根据气囊、管路、接头、阀中最弱部件的可核实额定及使用条件，确定工作／最高压力，配独立于电脑和程序的限压／泄压、过压断充气措施及压力指示，提供设定与台架校验记录。查明阀失电常态和手动卸压路径；断电不等于卸压。不猜压力数值，缺件／资料不明时不准入。
